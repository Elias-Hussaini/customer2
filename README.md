# E-managment | مدیریت ویزا

پیشخوان جامع مدیریت مشتریان، درخواست‌های ویزا، پرداخت‌ها و گزارش‌ها — کاملاً فارسی (RTL)، تقویم شمسی/میلادی، به‌صورت PWA نصب‌شدنی و آفلاین.

> **حریم خصوصی:** همهٔ داده‌ها فقط در مرورگر شما (IndexedDB) ذخیره می‌شوند. هیچ اطلاعات مشتری به هیچ سروری ارسال نمی‌شود. داده‌های مرورگر بین دستگاه‌ها هم‌گام‌سازی نمی‌شود — از «پشتیبان‌گیری» در تنظیمات برای انتقال استفاده کنید.

## امکانات

- **مشتریان و مدارک** — ثبت مشتری زیر نماینده و لیست، اسلات‌های مدرک (پاسپورت، تذکره، کارت ملی…)، فیلدهای سفارشی
- **دستیار هوشمند خواندن مدارک** — آپلود پاسپورت/تذکره (PDF یا عکس) و پر شدن خودکار فیلدها، کاملاً آفلاین و بدون سرویس ابری
- **پر کردن فرم ویزا (PDF)** — ذخیرهٔ قالب فرم‌های AcroForm و تولید خودکار PDF پرشده برای هر مشتری
- **درخواست‌های ویزا** — ثبت همزمان با مشتری، نوع ویزا، مبالغ و وضعیت‌ها
- **پرداخت‌ها** — با رسید عکس، محاسبهٔ مانده هر نماینده
- **گزارش‌ها** — خروجی PNG / PDF / Excel با جدول‌های عرض‌بالا
- **پشتیبان‌گیری** — JSON رمزنگاری‌شده (AES-GCM) + بایگانی ZIP از مدارک
- **کلیدهای میان‌بر** — Enter برای ذخیره، ff/cc/pp/ss/rr/dd و… (آموزش داخل تنظیمات)

## دستیار خواندن مدارک (موتور استخراج)

موتور استخراج **قاعده‌محور و قطعی** است — بدون هوش مصنوعی ابری، بدون OCR ابری، بدون ارسال مدرک به بیرون. هر چیزی که در مرورگر شما اجرا می‌شود: MRZ طبق ICAO Doc 9303، خواندن لایهٔ متن PDF (pdf.js) و OCR محلی (Tesseract.js).

### فرمت‌های پشتیبانی‌شده

| نوع مدرک | روش خواندن | فیلدها |
|---|---|---|
| پاسپورت (PDF با متن یا اسکن/عکس) | MRZ TD3 (2×44) + برچسب‌های انگلیسی | نام، نام خانوادگی، شماره، ملیت، تاریخ تولد/انقضا، جنسیت، شماره شخصی |
| کارت شناسایی الکترونیکی | MRZ TD1 (3×30) / TD2 | همان فیلدها + شماره ملی از دادهٔ اختیاری |
| تذکره / کارت با برچسب فارسی-دری | OCR فارسی + قواعد برچسب (نام، نام پدر، شماره تذکره…) | نیازمند بازبینی دستی — فیلدها با وضعیت «نیاز به بازبینی» علامت می‌خورند |
| PDF با لایهٔ متن (مثل نامه‌ها) | خواندن مستقیم متن — بدون OCR | هر آنچه با برچسب شناخته‌شده مطابقت داشته باشد |
| فرم درخواست ویزا (AcroForm) | شناسایی فیلدهای تعاملی و نگاشت | برای «پر کردن فرم» استفاده می‌شود |

- محدودیت فایل: **PDF / JPEG / PNG / WebP تا ۲۵ مگابایت، ۱۲ صفحهٔ اول**
- اعتبارسنجی MRZ: ارقام کنترل 7-3-1 (شماره سند، تاریخ تولد، تاریخ انقضا، شماره شخصی، رقم مرکب) + ترمیم هوشمند خطاهای رایج OCR (O↔0، I↔1…). فیلدی که ترمیم نشود هرگز «تأییدشده» نشان داده نمی‌شود.
- وضعیت هر فیلد جداگانه است: `تأیید شده / نیاز به بازبینی / نامعتبر / یافت نشد` — هیچ امتیاز کلی این عدم‌قطعیت را پنهان نمی‌کند.
- تاریخ‌ها به ISO (`1990-01-01`) نرمال می‌شوند؛ ورودی‌های میلادی، شمسی (۱۳۷۵/۰۱/۰۲)، ماه‌های دری (حمل، ثور…) و قالب‌های MRZ پشتیبانی می‌شوند. تاریخ نامعتبر هرگز حدس زده نمی‌شود.
- تطبیق با مشتریان موجود: شماره پاسپورت دقیق > نام+تاریخ تولد > نام > تاریخ تولد. **ادغام خودکار انجام نمی‌شود** — فقط گزینه‌های مشابه پیشنهاد می‌شوند.
- ترجمهٔ نام‌ها: دیکشنری قطعی لاتین↔فارسی (AHMADI↔احمدی…) + نقشهٔ حروف برای توکن‌های ناشناخته؛ همیشه قابل ویرایش در فرم.

### پر کردن فرم ویزا (PDF)

1. **مدیریت قالب‌ها → افزودن قالب**: فایل PDF فرم را بدهید؛ فیلدهای AcroForm خودکار شناسایی و به فیلدهای مشتری نگاشت می‌شوند (قابل تنظیم: منبع، قالب تاریخ ISO/DD-MM-YYYY/ماه انگلیسی/شمسی، بزرگی حروف، متن ثابت، الزامی).
2. **پر کردن فرم**: مشتری + قالب را انتخاب کنید، پیش‌نمایش نگاشت را ببینید و PDF پرشده را دانلود کنید.
3. فایل اصلی قالب **هرگز تغییر نمی‌کند** — همیشه نسخهٔ جدید ساخته می‌شود.
4. فیلدهای الزامیِ بدون مقدار به‌صراحت گزارش می‌شوند؛ **هیچ مقداری از خود ساخته نمی‌شود**.
5. فونت‌های استاندارد PDF فقط حروف لاتین (WinAnsi) پشتیبانی می‌کنند؛ متن فارسی به‌صورت **آوانویسی قطعی لاتین** نوشته می‌شود (کریمی → KARIMI) و در گزارش به اطلاع شما می‌رسد.
6. برای فرم‌های اسکن‌شده (بدون AcroForm) قالب مختصاتی قابل تعریف است: صفحه + مختصات + اندازهٔ قلم برای هر فیلد (فقط متن لاتین).

### حریم خصوصی

- پردازش کاملاً در مرورگر: PDF با pdf.js، OCR با Tesseract.js (WASM).
- تنها دانلود بیرونی، **یک بار** در اولین استفاده: مدل زبان OCR (`eng`/`fas` ~ چند مگابایت از CDN عمومی) که مرورگر کش می‌کند. خودِ متن و تصویر مدرک هرگز خارج نمی‌شود.
- فایل آپلودشده موقت است؛ فقط اگر خودتان تیک «ذخیره در مدارک مشتری» را بزنید در IndexedDB نگه داشته می‌شود (و فقط در بایگانی ZIP پشتیبان منتقل می‌شود).
- هیچ شمارهٔ پاسپورت یا متن مدرکی در لاگ‌ها نوشته نمی‌شود.
- قالب‌های فرم PDF هم فقط در IndexedDB شما ذخیره می‌شوند و **هرگز به Git ارسال نمی‌شوند**.

### افزودن پروفایل مدرک یا قالب جدید (توسعه‌دهنده)

- **پروفایل متنی/OCR**: در `src/lib/docex/text.ts` آرایهٔ `PROFILES` را گسترش دهید — هر `DocumentProfile` شامل برچسب‌ها (انگلیسی/فارسی/دری)، قواعد مقدار، زبان‌های OCR و تنظیم پیش‌پردازش است. کاملاً داده‌محور؛ بدون تغییر موتور.
- **قالب تاریخ خروجی PDF**: `DateFormat` در `src/lib/docex/fill.ts`.
- **نام‌های لاتین↔فارسی**: دیکشنری `NAME_TOKENS` در `src/lib/docex/translit.ts`.
- تست‌ها: `npm test` (vitest) — فیکسچرها کاملاً ساختگی هستند (اطلاعات هویتی جعلی).

