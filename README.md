# Customer Visa Management

React + TypeScript + Vite, designed as a local-first static application.

## Commands

- `npm run dev` - local development
- `npm run build` - production build
- `npm run preview` - preview the built app

## Important

Customer records and attachments must not be committed to a public GitHub
repository. Browser IndexedDB data is local to each browser and does not
automatically synchronize between devices. Keep backups.
